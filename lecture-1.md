## Live: VS Code demo

- New app, run, commit, push
- Run on a second device
- DevTools + widget tree
- Autocomplete (type a dot)

Notes:

- Baseline (like Worksheet 1): create app, run in Chrome, commit, push to GitHub.
- Second device: use the device selector to switch Chrome → Edge and re-run.
- DevTools widget inspector: open DevTools, enable "Select widget mode", click a widget in the running app, show it highlight in the widget tree, read its properties/constraints, spot padding/layout.
- Non-AI autocomplete: type an object then `.` to show the member dropdown; show parameter hints and quick docs on hover.
- Pro tips worksheets skip: rename symbol (F2), quick fix / lightbulb (⌘ .), go-to-definition (F12), format-on-save, hot reload vs hot restart.
- Add your own tips here.
