## Assessment — live demo

Create an app, run it in Chrome, switch devices, commit, and push to GitHub.

- Widget inspector demo: [docs.flutter.dev/tools/devtools/inspector](https://docs.flutter.dev/tools/devtools/inspector).

VS Code features:

- IntelliSense
- Member/completion after dot, seeing suggestions (autocomplete)
- Parameter hints (signature help) and hover / quick info (docs on hover)
- Rename symbol (F2)
- Quick fix / lightbulb (Cmd .)
- Format-on-save
- Hot reload vs hot restart.
